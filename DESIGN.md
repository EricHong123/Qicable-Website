## Overview

Qicable 面向工业线缆采购、设备工程师、系统集成商和 OEM 客户。界面应让访客快速确认接口与型号、看到实际装配及检测能力、提交带型号的询价。

本文件使用 design-md 格式，于 2026-10-09 从 `ui/src/tokens.css`、组件源码和浏览器计算样式提取，并同步本轮修复。它是当前实现的基线，不代表完整 WCAG 认证。原始问题见 [UI 审计](plans/2026-10-09-design-md-ui-audit.md)，已完成修改、实测范围及素材缺口见 [修复记录](plans/2026-10-09-design-md-ui-fixes.md)。后续按 [项目工作规范](AGENTS.md) 配合 design-md 与 typesafe-ai 技能。

保留已确认方向：黑橙品牌、真实工业图片、六大产品分类、六种语言（英／德／西／法／葡／阿）、首页三张图片背景轮播及叠加的 HTML 标题与按钮。保持既定 sitemap 和关键词布局。

## Colors

- `primary`：Logo 对应的橙色，用于主要询价按钮、选中状态与少量强调；按钮文字使用 `ink`。橙底白字只有 2.36:1，不作为小字号按钮方案。
- `brandInk`：白底文字链接或强调色，比主橙更深；白底对比度 6.40:1。
- `ink`／`muted`：主要内容／辅助内容，在白底分别为 17.58:1、5.88:1。
- `paper`／`soft`／`line`：白色主画布、浅灰分区、装饰分隔线。装饰线与控件可识别边界采用不同标准。
- `hero`／`heroMuted`／`heroLink`：深色首页场景与文字；文字区有渐变遮罩。图片叠加后的实际对比度仍须逐张检查，不能用纯色计算替代。
- `whatsapp` 仅用于 WhatsApp 联系入口，白色图标对比度 4.80:1，不扩展为品牌主色。
- `inputOutline` 为 `#7f8992`，对应 CSS `--control-outline`，白底对比度 3.56:1，已应用到表单、搜索、筛选和普通次级按钮边界。装饰分隔线继续使用 `line`。

## Typography

拉丁语系使用本地 IBM Plex Sans；阿拉伯语使用本地 IBM Plex Sans Arabic。实际加载 400／500／600 三种字重；正文回退 Arial／Tahoma／sans-serif。技术型号、接口名及数字需要保持可辨识，双向文本使用隔离。

frontmatter 中标题字号为相应 CSS 尺度的上限，以下规则说明响应变化：

| 用途 | 当前规则 |
| --- | --- |
| 首页主标题 | 桌面 `clamp(44px, 4.3vw, 64px)`；1440px 实测 61.92px；1280px 以下有 50px 覆盖 |
| 手机首页标题 | 720px 以下 `clamp(32px, 8.6vw, 44px)`；英语行高 1.12；阿语行高 1.22、无负字距 |
| 内页 H1 | 基础 `clamp(34px, 4.1vw, 58px)`，页面可有明确覆盖 |
| 产品详情标题 | `clamp(27px, 3vw, 40px)`，字重 500 |
| 常规正文／导语 | 16px／18px；本轮六篇技术指南 16px、1.85 行高 |
| 按钮／导航 | 15px／14px；导航并非正文 |
| 辅助说明／图片说明 | 14px／12px |

产品关键介绍使用 16px、1.6 行高；14px 留给辅助说明和规格备注。不要为了套用同一字号而放大所有元信息。保留既有 H1 关键词，排版只调整宽度、行长和断行。

## Layout

整体为横向内容区、充足纵向间距和真实图片交替。六大分类及接口导航优先于营销装饰。

- 内容 CSS 宽度为 `min(1320px, 100% - 96px)`；1440px 视口的实际内容区为 1280px（左右各 80px），另受生成样式的 container 上限影响。后续改布局须以计算样式验收。
- 980px 以下左右留白 32px，720px 以下为 20px；常规区块上下间距依次为 76／58／46px。
- 桌面导航从 1280px 起显示；更窄使用抽屉菜单。常规内容另有 980px、720px 断点；联系栏独立使用 767px 断点。
- 首页 Hero：文字覆盖背景场景；桌面给产品主体留出右侧空间；手机将主体安排在文字和 CTA 下方的同一 Hero 内。三张轮播仍在首页首屏。
- 产品详情：主图、型号、接口摘要及询价并列；技术参数在后续结构化区域。图片清晰度必须支持实际显示大小。
- 右下联系栏自上而下 WhatsApp／Email／表单。桌面 52px 按钮、8px 间隔、24px 边距；手机 46px 按钮、7px 间隔、右 12px／下 16px，并考虑安全区。
- 手机 Hero 控件与分类文案保留物理右侧至少 70px 的安全区域，并适配安全区；最窄 320px 下保持 44px 轮播触控目标。手机隐藏重复的数字计数，保留三个位置点和状态播报。桌面控件额外预留 56px 右内距；阿语桌面分类文案也预留同等空间。不要用层级掩盖布局冲突。

## Elevation

内容卡片主要用留白、浅灰背景及细边线分组。阴影集中在 Mega Menu、悬浮联系栏、提示和询价弹窗。

联系按钮阴影为 `0 4px 16px rgb(25 25 25 / 13%)`；询价弹窗为 `0 24px 80px rgb(25 25 25 / 22%)`，遮罩为 `rgb(15 18 21 / 56%)`。Hero 内容层级与固定联系栏不同，层级本身不解决按钮覆盖。

## Shapes

普通按钮、表单和图片框以 4px 小圆角为主；浮动联系按钮桌面 8px／手机 7px；询价弹窗桌面 10px／手机 8px。圆形仅用于轮播位置点等有明确用途的小控件。避免将工业产品卡全部改为大圆角胶囊。
