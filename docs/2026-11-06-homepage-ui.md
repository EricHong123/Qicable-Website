# 首页布局与全站圆角更新

本次增量调整首页的信息顺序与视觉层次，并统一网站的圆角。保留已有20种语言、产品身份、页面URL、Agent内容接口、询盘字段和埋点。

## 页面变化

- 产品分类提前展示，机器视觉使用更大的图片区域，其他五类保持清晰入口。
- 型号查找、配置核对和图纸定制改为紧凑的项目入口。
- 应用场景、制造与检验采用独立图文布局，复用已有图片和资料。
- 首页项目说明合并为一个四阶段流程，详细交付说明仍保留在内页。
- 证书、博客、FAQ和询盘表单重新组织层次，保留原有交互与目的页。

首页样式位于 `ui/src/homepage.module.css`；图文模块位于 `ui/src/home-editorial.tsx` 和对应 CSS module。

## 圆角约定

共享样式 `ui/src/tokens.css` 定义：控件12px、卡片18px、大面板24px、联系浮钮14px、提示标签8px。页面模块引用同一组变量。贴导航菜单只圆底边，贴底抽屉只圆顶边；圆形控件、表格单元格与分隔行保持原结构。
